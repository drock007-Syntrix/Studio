# Syntrix Studio (free)

Prompt-to-image studio with style presets, camera-move motion clips, and a gallery saved in your browser.
Runs entirely in the browser. Images come from Pollinations.ai's free public endpoint: no account, no key, no fees.

Open it: https://drock007-syntrix.github.io/Studio/
On iPad/iPhone: open the link in Safari → Share → Add to Home Screen.
